# 學會學｜我的學習實驗室

ewant《學會學：學習之道》榮譽作業 — 一個把學習科學轉化為可操作工具的互動式網站。

## 專案緣起
本作業從自身準備微積分、普通物理及轉學考的困境出發，結合一段實際完成的 AI 虛擬辦公室建置經驗，反思：為何有時能高度投入、有時卻陷入拖延？如何以學習科學改善，而非只依靠意志力？

本網站結合六個課程主題：
1. 習慣迴路與番茄鐘
2. 專注模式與發散模式
3. 主動回憶與能力錯覺
4. 記憶組塊與交錯練習
5. 間隔複習與睡眠
6. 自我效能與教學相長

## 網站功能
- 番茄鐘：25 分鐘專注、5 分鐘休息；完成專注時間後自動記錄一次學習區段
- 主動回憶卡片：翻卡自測、標記需複習/已掌握，並給出建議複習日期
- 錯題與盲點紀錄：記錄科目、錯誤、原因與下一步，保留在瀏覽器
- 七日學習實驗：可勾選每日完成狀態、追蹤過程而非只看結果
- 學習反思與個人案例：區分**已發生的經驗**與**尚未完成的計畫**

資料只存於使用者裝置的 `localStorage`，不會傳到伺服器，清除瀏覽器資料可能導致紀錄消失。

## 技術
純 HTML / CSS / JavaScript（不使用外部函式庫）；開啟 `index.html` 即可在瀏覽器使用。手機及桌面皆支援。

## 發布到 GitHub Pages
1. 前往儲存庫 **Settings → Pages**。
2. **Build and deployment → Source** 選擇 **Deploy from a branch**。
3. **Branch** 選擇 `main`、`/(root)`，按 **Save**。
4. 發布成功後網址通常是：https://limerence0527.github.io/learning/

> 只有在 GitHub Pages 真正啟用並部署成功後，上述網址才會提供網站。靜態網站不需要環境變數或伺服器。

## 使用與誠信
- 網站中的七日實驗是**執行計畫**，未自稱已全部完成。
- 番茄鐘及卡片統計反映該瀏覽器實際操作，不會預填成果。
- AI 是輔助解釋與檢查的工具，不替代自己的主動回憶及解題。
